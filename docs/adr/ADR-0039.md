# ADR-0039 — Descriptor-Driven Event Presentation

## Status

Accepted and implemented.

## Summary

ADR-0039 completes descriptor-driven presentation for transient Event
occurrences in both the Laptop Client and Desktop Runtime Host.

## Delivered

- Optional typed `EventPayloadDescriptor`
- Boolean, Numeric, String, and ByteArray payload metadata
- Backward-compatible Protocol V1 descriptor extension
- Optional gRPC Event payload descriptor
- Shared `EventPayloadFormatter`
- Stable missing, unexpected, mismatched, and unsupported diagnostics
- Attachment-generation-qualified descriptor resolution
- Descriptor-driven Laptop Client Event presentation
- Descriptor-driven Desktop Runtime Host Event presentation
- Deterministic multi-type validation Events

## Validation

- Automated tests: 3,762 passing
- Parameterless Event validated
- Boolean Event validated as `True`
- Numeric Event validated as `23.5`
- String Event validated without modification
- ByteArray Event validated as `01AB00FF`
- Desktop Runtime Host validated
- Laptop Client validated
- Commands initiated from both applications
- No diagnostics for valid occurrences

## Consequences

Properties, Commands, and Events now share the same architectural principle:
authoritative descriptors determine application interaction and presentation.
Events remain transient, non-replayed occurrences and do not become cached
runtime state.
