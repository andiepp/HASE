# ADR-0038 — Descriptor-Driven Command Editing

## Status
Accepted and Implemented

## Summary
ADR-0038 completes the descriptor-driven command interaction model for both the Laptop Client and Desktop Runtime Host.

## Delivered
- Shared CommandArgumentInputParser
- Descriptor-driven command editors
- Boolean, Numeric, String and ByteArray argument support
- Validation before execution
- Local preservation of invalid input
- Parameterless command compatibility
- Desktop and Laptop UI parity
- Typed Desktop command execution
- Activity logging of normalized command arguments

## Validation
- Automated tests: 3,692 passing
- Laptop Client validated
- Desktop Runtime Host validated
- Buffer.Replace ByteArray command validated
- Arduino parameterless commands validated
- ESP32 parameterless commands validated

## Consequences
Commands are now rendered and validated from descriptors in the same way properties are. The remaining interaction primitive to become descriptor-driven is Events (ADR-0039).
